# Stillwater House

A coastal hospitality website with a silent hero film, room and experience galleries, responsive navigation and a stay enquiry planner. HTML, CSS and JavaScript; all images, fonts and video are local.

## Run and deploy

Open `index.html`, or serve the directory with `python3 -m http.server 3000`. There is no build step. Import the repository into Vercel using the included configuration.

## Configuration

The planner produces a downloadable enquiry brief. It does not confirm reservations or process payments. Replace the property content and connect a real enquiry destination before a commercial launch.

The opening film has a still-image fallback. Motion respects reduced-motion and data-saving preferences. The typography licences are included in `assets/`.
